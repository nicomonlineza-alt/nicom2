# Nicom Online Website

A responsive, single-page Nicom Online website focused on intelligent web apps, AI agents, workflow automation, web design, hosting, and digital growth.

## Preview locally
Open `index.html` in a browser.

## Deploy
This is a static site and can be deployed to Vercel by importing this repository. No build command is required; set the output directory to the repository root.

## Contact form note
The contact form currently opens the visitor's email app with a prepared enquiry to `info@nicomonline.co.za`. It does not store leads on a server. Connect a form service or backend before relying on automatic lead capture.

## Design
Dark future-tech styling, neon green/cyan accents, glassmorphism cards, responsive mobile navigation, subtle reveal animations, and reduced-motion support.
